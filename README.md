# AthenaLMS
## Library & Librarian Management System

A Python-based Library Management System designed to manage books, librarians, borrowing records and overdue fines.

### Features
- Add and search books
- Manage book inventory
- Register librarians
- Assign active librarians
- Issue and return books
- Calculate overdue fines
- Track issued books

### Technologies Used
- Python
- Dictionaries and Lists
- Functions
- Conditional Statements
- Loops
- Datetime Module

### How to Run
1. install Termux in phone,  Ubuntu or Vscode in your system
2. pkg update && upgrade or sudo apt update && upgrade
3. pkg install git or sudo apt install git
4. pkg install python3 or sudo apt install python3 -y
5. git clone https://github.com/Krishna07862/AthenaLMS.git
6. cd cloned name 
7. allow permission 
8. type : python3 lib.py
